# Кровная вражда — таск 1

Только разведка и проверка, что мод вообще ставится. Игровых механик ещё нет.

Игра: The Witcher 3 **5.01**, Steam, все DLC, язык русский.
Скрипты сверены с дампом `Kitbein/The-witcher-3-nemesis`, коммит `a0934f1d947fd9d4101c1c626f30bac2bfd537a2`, папка `skripts/`.
Репозитория-образца `The-witcher-3-nemesis-grok` до этого коммита не было. Этот репозиторий — он и есть.

Компилятор WitcherScript здесь не запускался. Команда использует только функции, которые есть в ванильных скриптах. Первая проверка — в игре, по чек-листу ниже.

## Что поставить

В репозитории одна папка мода:

```
modKrovnayaVrazhda/
  content/
    scripts/
      local/
        krov_debug.ws
```

Папка мода обязана начинаться с `mod`. Файл лежит в `content/scripts/local/`, а не поверх ванильного пути, поэтому целый файл игры он не подменяет.

## Как установить

На скриншоте в папке модов лежат файлы Vortex (`vortex.deployment.msgpack`). Значит, модами управляет Vortex.

Надёжный путь:

1. Скачать этот репозиторий как ZIP (Code → Download ZIP).
2. Внутри архива должна оказаться папка `modKrovnayaVrazhda` с `content` внутри. Если ZIP завернул всё ещё в одну верхнюю папку — открой её, наружу нужна именно `modKrovnayaVrazhda`.
3. Vortex → Mods → Install From File, выбрать ZIP, где в корне лежит `modKrovnayaVrazhda`. Включить мод и нажать Deploy.
4. Если Vortex не подхватил архив, скопируй папку вручную в каталог модов игры, рядом с уже стоящими:
   `Steam\steamapps\common\The Witcher 3\mods\modKrovnayaVrazhda\`
   После ручного копирования не делай в Vortex Purge: он может стереть папку, которую положил не он.

## Как включить консоль

По странице REDkit «Enable debug console in-game» (6 июня 2024):

1. Открыть `The Witcher 3\bin\config\base\general.ini`.
2. В секцию `[General]` добавить строку `DBGConsoleOn=true`. Если секции нет — создать её.
3. Сохранить. Проверка файлов Steam эту правку затирает, тогда строку нужно вернуть.
4. В игре консоль открывается клавишей `~`. На русской раскладке это та же клавиша, что и `ё`.
5. Команды чувствительны к регистру. Скобки у команды без аргументов не обязательны.

## Чек-лист

1. Поставить папку, как выше. Запустить игру и загрузить сохранение в Велене (не главное меню).
2. Ожидание: игра запускается, окна ошибки компиляции скриптов нет.
3. Открыть консоль и ввести `krov_hello`, затем Enter.
4. Ожидание: слева на HUD, где обычно короткие сообщения, появляется текст `Krovnaya vrazhda: mod ustanovlen.`
5. Если текста нет, но игра не ругается: запусти `witcher3.exe` с параметром `-debugscripts`. После команды в `Documents\The Witcher 3\scriptlog.txt` должна быть строка канала `Krov`: `krov_hello: mod is loaded`.
6. Сохрани игру и загрузи сейв. Ожидание: сейв открывается. Мод ничего в сейв не пишет.

Команда из главного меню игрока не находит и пишет об этом только в лог. Это нормально: зайди в мир и вызови её снова.

## Если игра не запустилась

Окно «script compilation error» значит, что общий компилятор споткнулся об этот файл (или об конфликт имён). Игра при этом может не стартовать.

Откат: выключи мод в Vortex и сделай Deploy, либо удали папку `mods\modKrovnayaVrazhda`. Больше этот таск ничего не менял. `general.ini` трогать не обязательно, консоль можно оставить.

## Риски таска 1

- Кириллица в `.ws` сознательно не используется. Русские реплики позже пойдут отдельным текстовым файлом, не внутри кода.
- Мод не подменяет ванильные файлы, поэтому с уже стоящими модами (Nemesis, Blood and Steel, Spawn Control и остальные со скриншота) на этом шаге пересечений нет. Пересечения начнутся, когда появятся общие хуки. Это записано в `RESEARCH.md`.
- `LogChannel` сам по себе консоль не печатает. Видимая проверка — строка на HUD.
