# Таск 5. Как показывать охоту

Версия концепции 2.1. Проверка 24 ноября 2026 года на установленной Steam 5.01c, DX12, с русским текстом и текущей сборкой модов. Все пути к ванильным скриптам в таблице даны от `content/content0/scripts`.

| Возможность | Вердикт и выбранный способ | Основание |
| --- | --- | --- |
| Квест с этапами и счётчиком | Обновлять существующую цель в штатном журнале можно. Для собственной строки нужен зарегистрированный ресурс задания с целью и GUID. В проекте такого ресурса нет. Для примера выбраны собственный числовой факт, показ этапа на HUD и чтение текущего состояния в окне. | `game/journal.ws`, методы `GetEntryByTag`, `ActivateEntry`, `SetQuestObjectiveCount`. В `game/gui/menus/journalQuestMenu.ws` журнал строит дробь из текущего значения и `GetCount()` самой цели. Скриптовой фабрики для регистрации нового задания в просмотренном API не найдено. |
| «Журнал охоты» | Выбрано штатное окно, которое по запросу заново читает счётчик. Собственный самостоятельный экран требует регистрации меню и ресурса интерфейса. Для книги доступна вкладка глоссария, но отдельное динамическое представление добавило бы зависимость или дополнительные обёртки. | `game/gui/r4guimanager.ws`, метод `ShowUserDialogAdv`, параметр локализации выключен для готовой строки. `game/gui/menus/glossaryMainMenu.ws` маршрутизирует зарегистрированные вкладки. В установленном SharedUtils есть отдельный пример добавления записей в книги. |
| Метка и область поиска | Можно. При открытии карты добавляем отображаемую точку с подписью и радиусом. Для демонстрации центр находится на 120 м восточнее текущего положения Геральта, радиус 60 м. Видна на карте мира текущего региона. | `game/gui/menus/mapMenu.ws`, `UpdateData` → `UpdateEntityPins` → `StaticMapPinData`. Ваниль заполняет поля `posX`, `posY` и `radius`. Штатный массив пересоздаётся при обновлении карты. |
| Настройки модов | Можно через отдельную XML-группу, начальное значение в INI и чтение через `CInGameConfigWrapper`. Выбран тестовый переключатель короткого уведомления. Для подраздела использован ванильный заголовок элементов интерфейса. | `game/inGameConfigWrapper.ws`, `GetVarsNumByGroupName` и `GetVarValue`. Разбор пути группы по точкам и тег `nonLocalizedName` — в `game/gui/main_menu/ingamemenu/igmOptions.ws`. Структура XML сверена с `hud.xml` игры и XML установленного All Quest Markers. |
| Краткие уведомления | Можно. `krov_ui_notify()` читает переключатель и при значении 1 передаёт локализованную строку на обычный HUD. Подтверждения диагностических команд выводятся независимо от переключателя. | `game/player/r4Player.ws`, метод `DisplayHudMessage`. Язык выбирается через `GetCurrentTextLocCode` из `game/inGameConfigWrapper.ws`. |

## Что проверено в игре

Игра дошла до главного меню и загрузила существующий сейв в Велене. Для вызова обычных консольных команд использовался установленный TW3SE. В самих файлах мода вызовов TW3SE нет.

- На экране прочитана строка «Свергнуть зло — собрать сведения: 1/2» в окне с кнопкой OK. В этой версии игры тело окна видно, отдельный заголовок визуально не выделяется.
- После выставления 2 в `scriptslog.txt` появилась строка `[Krov] krov_ui_step Свергнуть зло — открыть цель. Сведения: 2/2`. После сброса счётчик вернулся к 0.
- На карте Велена к востоку от Геральта видны центр и белый полупрозрачный круг. Одновременно осталась видна зелёная личная булавка игрока. В том же обновлении карты записано `[Krov] krov_ui_map: submitted marker, radius=60`.
- Игра прочитала зарегистрированную XML-группу со значением по умолчанию `1`. При ручной проверке пользователя игра записала `false` при выключении и `true` при включении. Это видно в `scriptslog.txt` и подтверждается сохранённым значением `true` в `dx12user.settings`. Первая версия пропускала уведомление только при строке `1`, поэтому включение через меню его не возвращало. Исправленные команды используют одну функцию чтения, которая приводит `true` и `1` к `1`, а `false` и `0` к `0`. Повторная игровая проверка исправления остаётся открытой. Английский язык, DX11 и установка без Settings Updater в этот прогон не входили.

## Установка, повторение и откат

В текущую игру добавлены четыре файла поверх работающего таска 4. Для повторной ручной установки распаковать `krov_task5.zip` в корень игры, совместив одноимённые папки `Mods` и `bin`. Архив включает полные скрипты тасков 1–5. При управлении через Vortex использовать архив как обновление предыдущей сборки. Не включать одновременно два пакета с одними и теми же скриптами. Общих файлов со списками XML в архиве нет.

1. В загруженном мире ввести `krov_ui_step(1)`, затем `krov_ui_journal()`. Ожидаются «собрать сведения» и 1/2. Закрыть окно клавишей Enter.
2. Ввести `krov_ui_step(2)`, затем снова открыть журнал. Ожидаются «открыть цель» и 2/2.
3. Ввести `krov_ui_map(1)` и открыть карту мира. На фильтре «Всё» справа от Геральта виден круг. При выборе центра в описании указан радиус 60 м. Ввести `krov_ui_map(0)` и переоткрыть карту. Тестовая область исчезает.
4. В настройках открыть раздел модов и подраздел элементов интерфейса. Найти «Кровная вражда / Blood Feud — HUD». Выключить, применить, вернуться в мир и ввести `krov_ui_config()`, затем `krov_ui_notify()`. Ожидаются значение 0 и отсутствие тестовой фразы. Включить обратно и повторить обе команды. Ожидаются значение 1 и «Проверка интерфейса».
5. Ввести `krov_ui_step(0)`. Следующее открытие журнала показывает 0/2. В тестовом прогоне выполнены сброс счётчика и отключение метки. Ручное сохранение для проверки не требуется.

Для отката текущей ручной установки закрыть игру и убрать только следующие четыре файла относительно её корня:

- `Mods/modKrovnayaVrazhda/content/scripts/local/krov_ui.ws`
- `Mods/modKrovnayaVrazhda/content/scripts/local/krov_ui_text.ws`
- `bin/config/base/krov_ui.ini`
- `bin/config/r4game/user_config_matrix/pc/krov_ui.xml`

Если новая версия установлена целиком через Vortex, отключить её, включить принятый архив таска 4 и выполнить Deploy. Две демонстрационные записи Facts DB удаляются командами сброса выше в том сохранении, в котором команды выполнены. Возможное пересечение с модами карты описано в `HOOKS.md`. При другой сборке фильтры значков или настройки скрытия областей могут изменить вид круга.
