# Прогресс проекта

Таски 1–5 выполнены и приняты пользователем. Таск 5 проверен в игре, включая переключатель уведомлений после исправления чтения true/false.

Продолжать с таска 6 по концепции 2.1 только после подтверждения пользователя. Исследования находятся в docs/RESEARCH.md и docs/RESEARCH_UI.md. Вмешательства перечислены в HOOKS.md.

Исходники мода находятся в src/modKrovnayaVrazhda, конфиги — в src/bin. Ванильные скрипты не копировались. API сверять с content/content0/scripts установленной Steam-игры. Тесты тасков 1–4 выполнял пользователь. Статический анализ не считать игровым тестом.
