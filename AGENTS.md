# Правила работы над модом

- Выполняй только текущий таск. Не переходи дальше без подтверждения пользователя.
- Используй текущую концепцию CONCEPT.md версии 2.1 и TASKS.md. Устаревшая версия находится в docs.
- Отмечай прогресс в PROGRESS.md, изменения — в CHANGELOG.md, API исследования — в docs/RESEARCH.md и docs/RESEARCH_UI.md, вмешательства — в HOOKS.md.
- Исходный код мода хранится в src/modKrovnayaVrazhda. Конфиги мода хранятся в src/bin. Не перемещай эти папки без обновления путей установки в документации.
- Папка docs содержит исследования, установку и архивы этапов. tests предназначена для проверочных сценариев. vanilla_scripts — для выборочных примеров ванильного кода. Не копируй туда весь каталог игры.
- Не выдумывай WitcherScript API. Сверяй сигнатуры с установленной игрой Steam 5.01 по content/content0/scripts.
- Не выдавай статический анализ за игровой тест. Явно указывай, кто и как проверил изменение.
- Не добавляй новые платные сервисы или платные API. Не запускай агентов без существенной пользы.
- Не создавай Git-коммит и не переходи к следующему таску без отдельного подтверждения пользователя.
